# Roadmap

- **M0 — Hecho:** arquitectura portable, almacenamiento, estructura y pruebas.
- **M1 — Hecho:** UI tipo consola, fullscreen manual, responsive, teclado/mando básico.
- **M2 — Hecho:** biblioteca local, búsqueda, filtros, favoritos, recientes y estadísticas.
- **M3 — Hecho:** añadir y lanzar juegos de PC.
- **M4 — Base funcional:** configurar emuladores y lanzar ROMs con `{rom}`.
- **M5 — Base funcional:** carpetas y escaneo incremental sin borrar originales.
- **M6 — En progreso:** perfiles de mando, remapeo y selección del mando principal.
- **M7 — Pendiente:** carátulas manuales y proveedores de metadatos opcionales.
- **M8 — Base funcional:** tiempo jugado y estadísticas; ampliar sesiones e informes.
- **M9 — Pendiente:** backups/restauración de partidas con confirmaciones.
- **M10 — Base funcional:** diagnóstico; ampliar autocorrecciones y pruebas de emuladores.
- **M11 — Pendiente:** actualizaciones portables con rollback.
- **M12 — Preparado estructuralmente:** temas, plugins y nuevas plataformas.
